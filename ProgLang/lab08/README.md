### Задание 3 **(2)**

*Напишите пример программы на* **Java** *с двумя вложенными циклами и инструкцией* **break** *для выхода
из двух вложенных циклов. В качестве такой программы можно взять поиск первого нуля в двумерном массиве.*

**Решение:**

```java
public class Main {
    public static void main(String[] args) {
        int[][] a = {
            {1, 2, 3},
            {4, 0, 6},
            {7, 0, 9}
        };

        search:
        for (int i = 0; i < a.length; i++) {
            for (int j = 0; j < a[i].length; j++) {
                if (a[i][j] == 0) {
                    System.out.println("Ноль найден: строка " + i + ", столбец " + j);
                    break search;
                }
            }
        }
    }
}
```

Для выхода сразу из двух вложенных циклов используется метка `search`. Инструкция `break search` завершает оба цикла, когда найден первый ноль.

### Задание 4 **(2)**

```
a = list(range(10))
b = [a.pop() - x for x in a]
print(*b)
```
*Объясните, почему список* **b** *получился именно таким.*

**Решение:**

Во время выполнения генератора списка цикл идет по элементам списка `a` с начала, а метод `a.pop()` на каждом шаге удаляет и возвращает элемент с конца. Из-за удаления элементов длина списка уменьшается на каждом шаге, поэтому цикл проходит только первые 5 элементов (от 0 до 4) и вычитает их из последних (от 9 до 5). Затем индекс доходит до новой длины списка, равной 5, и цикл завершается. В результате получается список `[9, 7, 5, 3, 1]`.

### Задание 5 **(2)**

*Напишите программу на С++, которая прочитает натуральное число* **n**, *создаст вектор
из* **n** *элементов, прочитает значения элементов, добавит последний элемент вектора к каждому элементу 
(в том числе и к последнему), найдет и выведет количество положительных и отрицательных элементов вектора
после изменения. Из циклов в программе можно использовать только циклы по коллекции.*

**Решение:**

```cpp
#include <iostream>
#include <vector>

using namespace std;

int main() {
    int n;
    cin >> n;
    vector<int> a(n);
    for (int &x : a) {
        cin >> x;
    }

    int last = a.back();
    for (int &x : a) {
        x += last;
    }

    int positive = 0;
    int negative = 0;
    for (int x : a) {
        if (x > 0) {
            positive++;
        } else if (x < 0) {
            negative++;
        }
    }

    cout << positive << " " << negative << endl;
    return 0;
}
```

Сначала программа считывает элементы вектора. Затем сохраняет последний элемент и прибавляет его ко всем элементам вектора. После изменения подсчитывает количество положительных и отрицательных элементов.

### Задание 6 **(3)**

*Представим, что в некотором будущем стандарте* **С++** *появится конструкция*
```
forc(i, from, to)
```
*которая будет раскрываться в следующий код.*
```
{
   int __i = from, __n=to;
   for(const int &i= __i; i < __n; __i++) {
      ...
   }
}
```
*Чем эта конструкция отличается от стандартного цикла* **for**? *Укажите два основных различия.
Напишите программы для демонстрации этих различий.*

*Написанные программы сохраните в папку с номером задания.*

**Решение:**

Два основных различия:

1. Вычисление верхней границы: в конструкции `forc` выражения `from` и `to` вычисляются один раз при создании переменных `__i` и `__n`. В обычном цикле `for (int i = from; i < to; ++i)` выражение `to` проверяется заново при каждой проверке условия.
2. Изменяемость счётчика: в конструкции `forc` переменная `i` объявлена как константная ссылка `const int &i` на внутреннюю переменную `__i`. Изменять `i` напрямую нельзя, тогда как обычный счётчик `for` можно изменять.

**Первое отличие — вычисление верхней границы:**

Программа с циклом `forc`:
```cpp
#include <iostream>

using namespace std;

int main() {
    int to = 3;
    {
        int __i = 0, __n = to;
        for (const int &i = __i; i < __n; __i++) {
            cout << i << " ";
            to--;
        }
    }
    cout << endl;
    return 0;
}
```
Вывод: `0 1 2`. Переменная `__n` сохраняет начальное значение `3`, поэтому изменение `to` внутри цикла не влияет на количество повторений.

В стандартном цикле `for` будет такой:
```cpp
#include <iostream>

using namespace std;

int main() {
    int to = 3;
    for (int i = 0; i < to; i++) {
        cout << i << " ";
        to--;
    }
    cout << endl;
    return 0;
}
```
Вывод: `0 1`. В обычном цикле значение `to` меняется и повторно проверяется на каждом шаге, из-за чего цикл завершается раньше.

**Второе отличие — изменяемость счётчика:**

В конструкции `forc` переменная `i` является константной ссылкой, поэтому попытка изменить счётчик вызовет ошибку компиляции:
```cpp
int to = 5;
{
    int __i = 0, __n = to;
    for (const int &i = __i; i < __n; __i++) {
        ++i;
    }
}
```

Этот код не скомпилируется, так как переменная `i` доступна только для чтения.
В обычном цикле `for` счётчик не является константой, поэтому его изменение внутри тела цикла разрешено:
```cpp
for (int i = 0; i < to; i++) {
    ++i;
}
```

Ошибки нет, значение счётчика успешно изменяется

### Задание 7 **(2)**

*Напишите программу на языке* **Python** *для проверки того, что все числа во введенной 
последовательности неотрицательные. Если в цикле будет найдено отрицательное число, цикл должен
прерваться и вывести найденное число. Если отрицательных чисел нет, то вывести некоторое сообщение об этом.*

*Программа должна использовать конструкцию* **for break else**.

*Запишите аналогичную программу на С++. Какие изменения в алгоритме решения в ней появились?. Почему?*

*Написанные программы сохраните в папку с номером задания.*

**Решение:**

**Python**

```python
a = [int(x) for x in input().split()]
for x in a:
    if x < 0:
        print(x)
        break
else:
    print("Все числа неотрицательные")
```

В языке C++ нет конструкции `for ... else`, поэтому для проверки завершения цикла добавлена логическая переменная `found`. Внутри цикла при нахождении отрицательного числа переменная `found` принимает значение `true` и цикл прерывается с помощью `break`. После окончания цикла проверяется значение `found`, и если отрицательных чисел не было найдено, выводится соответствующее сообщение.

**C++**

```cpp
#include <iostream>
#include <string>
#include <sstream>
#include <vector>

using namespace std;

int main() {
    string s;
    getline(cin, s);
    stringstream ss(s);
    vector<int> a;
    int x;
    while (ss >> x) {
        a.push_back(x);
    }

    bool found = false;
    for (int v : a) {
        if (v < 0) {
            cout << v << endl;
            found = true;
            break;
        }
    }
    if (!found) {
        cout << "Все числа неотрицательные" << endl;
    }
    return 0;
}
```

###  Задание 9 **(3)**
*Напишите программу на языке Python для решения следующей задачи.*

*Задана пронумерованная последовательность логических значений* **t(0),t(1),..,t(n)**, **t(i) ∈ {False,True}**

*Последовательность обладает следующим свойством: существует некоторое число k такое, что 
все значения* **t(0),t(1),...,t(k-1)** *равны* **False**, *а все значения* **t(k), ... , t(n)** *равны* **True**,
*то есть слева от* **k** *находятся значения* **False**, *а справа* - **True**. *Последовательность задается
функцией* **t(i)**, *которая возвращает логическое значение. Например, для тестирования эту функцию можно
задать следующим образом.*
```
def t(i):
   return i>=1000
```

*Требуется написать программу, которая найдет число* **k**. *Программа должна реализовывать алгоритм 
бинарного поиска. Диапазон поиска задается переменными* **left** и **right**. *На каждом шаге вычисляется
центр диапазона, значение в нем проверяется, после чего диапазон сокращается в два раза.*

*Алгоритм должен быть записан через цикл* **while** *и реализовывать инвариант цикла*

t(left)=False ∧ t(right)=True

```
left = -1
right = 10**18
while ...:
   mid = ...
   if t(mid):
      ...
   else:
      ...
print(...)
```

**Решение:**

```python
def t(i):
    return i >= 1000

left = -1
right = 10**18
while right - left > 1:
    mid = (left + right) // 2
    if t(mid):
        right = mid
    else:
        left = mid
print(right)
```

На каждом шаге бинарного поиска вычисляется середина диапазона. Если `t(mid)` возвращает `True`, правая граница сдвигается к середине, иначе сдвигается левая. Цикл заканчивается, когда между границами остаётся один элемент, и программа выводит `right`.
