### Задание 1 **(2)**
*Рассмотрим следующую программу.*
```
d = {'sep': ',' , 'end': '\n'}
l = ['Утопия', 14, 'Вселенная', 25]
print (l, d)
print (*l, d)
print (*l, *d)
print (*l, **d)
```
*Объясните результаты ее работы.*

*При устном ответе на вопросы вам потребуется рассказать, что такое "Утопия 14" и "Вселенная 25".*

**Решение:**

Программа выводит:
```
['Утопия', 14, 'Вселенная', 25] {'sep': ',', 'end': '\n'}
Утопия 14 Вселенная 25 {'sep': ',', 'end': '\n'}
Утопия 14 Вселенная 25 sep end
Утопия,14,Вселенная,25
```

Объяснение результатов:
1. `print(l, d)` — список `l` и словарь `d` передаются как два позиционных аргумента и выводятся через пробел.
2. `print(*l, d)` — оператор `*` распаковывает список `l` на отдельные элементы, а словарь `d` выводится последним аргументом.
3. `print(*l, *d)` — распаковываются элементы списка `l` и ключи словаря `d` (`'sep'` и `'end'`), все значения выводятся через пробел.
4. `print(*l, **d)` — оператор `**` распаковывает словарь `d` в именованные параметры функции `print` (`sep=','` и `end='\n'`). Элементы списка выводятся через запятую.

### Задание 2 **(2)**
*Напишите функцию* **sublist** для решения следующей задачи.*

*На вход функции поступает список или кортеж и набор номеров позиций.
Функция должна составить и вернуть список из элементов, которые
находятся на этих позициях. Примеры работы приводятся ниже. Работа функции должна строго им соответствовать.*

```
>>> lst = [ 'Anna', 'Barbara', 'Clara', 'Diana', 'Eva', 'Flora']
>>> sublist(lst, 0, 2, 5)
['Anna', 'Clara', 'Flora']
>>> sublist (lst)
[]
>>> sublist(lst, 0, 1, 2, 3, 4, 5)
['Anna', 'Barbara', 'Clara', 'Diana', 'Eva', 'Flora']
```

**Решение:**

```python
def sublist(seq, *indices):
    return [seq[i] for i in indices]

lst = ['Anna', 'Barbara', 'Clara', 'Diana', 'Eva', 'Flora']
print(sublist(lst, 0, 2, 5))
print(sublist(lst))
print(sublist(lst, 0, 1, 2, 3, 4, 5))
```

Конструкция `*indices` принимает произвольное количество номеров позиций в виде кортежа, а генератор списка выбирает из `seq` элементы с указанными индексами.

### Задание 3 **(1)**

*Задан список* **lst** *из натуральных чисел*. *Напишите фрагмент
программы, состоящий из одного вызова функции* **max**, *который найдет в этом списке число с максимальным
числом единиц в двоичной записи.* 

*Многоточие надо заменить на лямбда-функцию, использующую фукцию* **bin** *и метод строк* **count**.

*Пример работы приводится ниже.*
```
>>> lst = list(range(6000 ,7000))
>>> ans = max(lst,...)
>>> print(ans)
6143
```

**Решение:**

```python
lst = list(range(6000, 7000))
ans = max(lst, key=lambda x: bin(x).count('1'))
print(ans)
```

Функция `bin(x)` переводит число в двоичную строку, а метод `count('1')` подсчитывает количество единиц. По этому значению функция `max` выбирает число с наибольшим числом единиц.

### Задание 4 **(2)**

*Запишите фрагмент программы, которая упорядочит список слов
по длине, а при равенстве длины - лексикографически. Сортировка
должна состоять из одного вызова метода* **sort**.

*Пример работы приводится ниже.*

```
>>> lst = ['hello', 'hell', 'bye', 'world', 'bybye']
>>> lst.sort (...)
>>> print (lst)
['bye', 'hell', 'babye', 'hello', 'world']
```

**Решение:**

```python
lst = ['hello', 'hell', 'bye', 'world', 'bybye']
lst.sort(key=lambda x: (len(x), x))
print(lst)
```

В качестве ключа сортировки передается кортеж `(len(x), x)`. В Python кортежи сравниваются поэлементно: сначала по длине строки `len(x)`, а при одинаковой длине — по алфавиту `x`.

### Задание 5 **(2)**

*Напишите программу для решения следующей задачи.*

*В одной строке через запятую записана последовательность слов. Перед
запятой или после нее могут быть пробелы, сами слова пробелов не
содержат. Программа должна вывести в одной строке через запятую
последовательность чисел, равных длине каждого слова. Например,
для ввода*
```
hello   ,   world ,   and ,   goodbye
```
*программа должна вывести*
```
5, 5, 3, 7
```
*Программа должна быть написана с использованием парадигмы функционального программирования, то есть без использования циклов, присваиваний и т.д. Программа может использовать функции* **input**, **print**, **len**, **map** *и методы строк* **split** и **strip**.*

**Решение:**

```python
print(*map(len, map(str.strip, input().split(','))), sep=', ')
```

Метод `split(',')` разбивает строку на части по запятой. Первый `map` применяет `str.strip` к каждому слову для удаления лишних пробелов, а второй `map` применяет `len` для получения длин слов. Результат распаковывается в `print` с разделителем `sep=', '`.

### Задание 6 **(2)**

*Запишите генератор в форме функции, который будет создавать
последовательность по следующему правилу.*

* *Если текущее число x в последовательности четное, то следующее число равно x/2.*
* *Иначе следующее число равно 3x + 1.* 

*Последовательность начинается с заданного числа n и заканчивается единицей.*

*Далее приведен пример работы генератора.*
```
>>> print (*gen(7))
7 22 11 34 17 52 26 13 40 20 10 5 16 8 4 2 1
```

**Решение:**

```python
def gen(n):
    yield n
    while n != 1:
        if n % 2 == 0:
            n //= 2
        else:
            n = 3 * n + 1
        yield n

print(*gen(7))
```

Генератор сначала возвращает начальное число `n`, а затем в цикле пересчитывает его значение по правилу и возвращает каждое число через `yield`, пока не получится 1.

### Задание 7 **(2)**

*Напишите генератор, который для заданной последовательности*
**seq** *будет задавать последовательность из каждого второго элемента* **seq**.

```
def every_other ( seq )
    ...
```
*Ниже приведены примеры использования генератра.*
```
>>> print (*every_other([10, 20, 30, 40, 50]))
10 30 50
>>> print(*every_other(range(10)))
0 2 4 6 8
>>> print(*every_other(iter(range(10))))
0 2 4 6 8
>>> print(sum(every_other(map(int, input().split()))))
2 5 11 3 8
21
```

**Решение:**

```python
def every_other(seq):
    for i, x in enumerate(seq):
        if i % 2 == 0:
            yield x

print(*every_other([10, 20, 30, 40, 50]))
print(*every_other(range(10)))
print(*every_other(iter(range(10))))
```

Функция `enumerate` нумерует элементы последовательности или итератора, а условие `i % 2 == 0` отбирает элементы с четными индексами (каждый второй элемент, начиная с первого).

>>> n = 5

###  Задание 10 **(1)**
*Какие из указанных функций и методов Python соответствуют определению чистых функций?
В случае отрицательного ответа требуется дать пояснение.*

* **file.readline|** — *чтение строки из файла.*
* **len** — *определение длины строки или количества элементов в контейнере.*
* **list.append** — *добавление в список нового элемента.*
* **sum** — *нахождение суммы.*
* **sorted** — *построение сортированного списка.*
* **list.sort** — *сортировка списка.*
* **random.randint** — *генерация случайного целого числа.*
* *Разворот списка.*
```
def rev(x):
    return x[::-1]
```
* *Выбор нескольких элементов из хвоста списка.*
```
tail_len = 3
def tail(x):
    return x[-tail_len:]
```

**Решение:**

- **file.readline** — не является чистой функцией. Пояснение: изменяет состояние файла (сдвигает указатель чтения) и при повторных вызовах возвращает разные строки.
- **len** — чистая функция.
- **list.append** — не является чистой функцией. Пояснение: изменяет переданный список на месте.
- **sum** — чистая функция.
- **sorted** — чистая функция.
- **list.sort** — не является чистой функцией. Пояснение: изменяет исходный список на месте.

- **rev(x)** — чистая функция.
- **tail(x)** — не является чистой функцией. Пояснение: зависит от глобальной переменной `tail_len`. При изменении `tail_len` результат функции для одного и того же списка изменится.

###  Задание 11 **(2)**
*Рассмотрите следующую функцию.*
```
def toint(fun):
    def wrapper(*args):
        return fun(*map(int, args))
    return wrapper
```
*Что передается в функцию* **toint**? *Что возвращает эта функция?*
*Что делает функция* **wrapper**?
*Придумайте несколько примеров использования* **toint**.

**Решение:**

1. В функцию `toint` передается исходная функция `fun`.
2. Функция `toint` возвращает новую функцию `wrapper`.
3. Функция `wrapper` принимает аргументы `*args`, переводит каждый в целое число через `map(int, args)` и передает в функцию `fun`.

**Примеры использования:**

**Пример 1**

```python
def add(a, b):
    return a + b

f = toint(add)
print(f("10", "20"))
```

Вывод: `30`. Функция складывает строки, предварительно преобразовав их в целые числа.

**Пример 2**

```python
def mult(a, b):
    return a * b

f = toint(mult)
print(f("3", "4"))
```

Вывод: `12`. Функция переводит строки в целые числа и перемножает их.

**Пример 3**

```python
f = toint(max)
print(f("2", "10", "3"))
```

Вывод: `10`. Функция `max` сравнивает аргументы как числа, а не как строки.
